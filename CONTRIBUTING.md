# Contributing

Bug reports and confirmed test results from Creative Stage SE MF8410 owners are welcome.

Please include:

- Device model from the physical label
- Country/region and approximate purchase date, if known
- Operating system used to run the patcher
- Official input SHA-256 reported by the patcher
- Whether the firmware flashed successfully
- Which prompts were tested

Do **not** attach or link Creative's firmware, extracted MP3 files, encryption material or copyrighted manuals. Logs and screenshots should not contain private information.

Changes to the patch must preserve exact-input and exact-output checksum validation. Pull requests should include a clear rationale and reproducible validation steps.
